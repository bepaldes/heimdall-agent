The Heimdall Way of Working (Beyond a Skill Aggregator)

Skills alone do not build reliable software. Heimdall enforces six operational disciplines on every turn:

Communication

1. BLUF (Bottom Line Up Front)

Every report, plan, code review verdict, and subagent handoff opens with the conclusion, verdict, and blast radius in the first 1–2 sentences using standardized headers (Subagent BLUF, Review Verdict, Plan BLUF).

Precision

2. ASD-STE100 Simplified Technical English

Procedural steps start with active imperative verbs (Create, Assert, Verify, Run), stay at ≤20 words per step, name objects explicitly, and ban vague qualifiers.

Poteto / pstack

3. High-Rigor Craftsmanship

pstack-discipline enforces Prove It Works, Fix Root Causes, Test Behavior Not Implementation, and Subtract Before You Add—paired with thermo, karpathy-guidelines, clean-code, and modern-web-guidance.

brainmaxxing

4. Self-Healing Sessions (ruminate + handoff)

ruminate mines Claude and Gemini session transcripts for corrections and trigger failures. Rules in handoff and writing-plans were extracted directly from 187 sessions, paired with the 75%/40-turn Context Sentinel.

Multi-Model

5. Dynamic Cross-Family Routing

Personas use model: inherit. heimdall sync-models and lib/model-router.cjs classify capabilities dynamically and select cross-family Goldfish reviewers (Claude, Gemini, Codex, GLM, Hunyuan, MiMo).

Restraint

6. Token, Ceremony & Diff Restraint

progressive-disclosure loads skills on demand, caveman strips conversational ceremony, and ponytail (Lazy Senior Dev Mode) enforces the smallest complete diff and a one-read reply.

Matt Pocock · Karpathy

7. Real Engineering Pipeline & 4 Pillars

mattpocock/skills chains grill-me → wayfinder → domain-modeling → to-spec → to-tickets → codebase-design → handoff. karpathy-guidelines enforces Think Before Coding, Simplicity First, Surgical Changes, and Goal-Driven Execution.

Triage

8. Upstream Sync (upstream-skill-sync)

Classifies skills as mirror, adapted, or native in config/skills.json and triages upstream updates into Tier 1 (Safe 1:1), Tier 2 (Selective Merge), or Tier 3 (Reject) after security scanning.

ASD-STE100 Zero-Vagueness Lexicon

Banned Word Why Prohibited STE Replacement Pattern
ensure Does not specify the verification mechanism. Verify <condition> equals <expected>. If not, <action>.
properly Subjective without testable criteria. Assert <field> matches regex <pattern>.
appropriately Defers specification to the executor. State the exact configuration parameter or value.
gracefully Vague error-handling requirement. Catch <ErrorType>, log warning, and return <FallbackValue>.
as needed / etc. Unbounded scope; executor cannot guess items. List all conditions and items exhaustively.

Single Source of Truth Architecture

Heimdall deploys live NTFS junctions (Windows) or POSIX symlinks (macOS/Linux) from one repository so all installed AI tools stay synchronized with zero file duplication.

Event-Driven Lifecycle Hooks

Zero-dependency runtime guardrails declared in hooks/hooks.json and executed by hooks/heimdall-hook.cjs, plus a universal native Git pre-push hook.

Event / File Matcher Enforced Behavior
UserPromptSubmit .* Injects compact BLUF + ASD-STE100 reminder (verdict first, imperative verb, ≤20 words/step, zero banned words).
PreToolUse Bash|PowerShell Blocks destructive root commands (exit 2), blocks dev servers (Strict Zero Dev-Server Policy), blocks force-push on protected branches, blocks staging .env/id_rsa/*.pem, and runs Context Sentinel (75% / 40-turn warning).
PreToolUse Write Emits Karpathy 800-line advisory (exempting HTML/SVG/OpenDesign data-od-id artifacts) and updates Context Sentinel tracking.
PreCompact .* Clears temporary session state and reminds the agent to persist active tasks, rulings, and ledgers to disk.
hooks/git/pre-push Git push Universal shell hook blocking non-fast-forward pushes to main/master across all harnesses and terminal sessions.

Install, CLI & MCP Commands

# Bootstrap full ecosystem with live junctions
git clone https://github.com/bepaldes/heimdall-agent.git
cd heimdall-agent
node setup.mjs --clean --link --yes

# Daily CLI
heimdall sync          # Sync junctions across installed tools
heimdall audit         # Audit installed tools, endpoints, and skill counts
heimdall sync-models   # Refresh dynamic model catalog and cross-family routing
heimdall update-skill all

# MCP management (direct node.exe invocation, zero npx spawning)
/mcp-sync              # Resolve config/mcp.template.json and sync harnesses
/mcp-cleanup           # Terminate orphaned MCP processes
