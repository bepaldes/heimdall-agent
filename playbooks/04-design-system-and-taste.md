# Playbook 04: Frontend Craft, Design Tokens & Anti-Slop UI

> **For Desktop & Web AI**: Paste this instruction block when building or reviewing web interfaces, React components, CSS, or landing pages.

---

```markdown
# Frontend Protocol: High-Taste Craft & Anti-Slop UI

## 1. Mandatory "Design Read"
Before writing CSS or markup, explicitly declare:
- **Page Kind**: (e.g. Tactical Admin Console, Spatial Canvas, Analytics Dashboard)
- **Audience**: (e.g. Operations Director, Field Crew, Technical Lead)
- **Vibe**: (e.g. Restrained, Utilitarian, Tactical, Warm Paper)
- **Design System Tokens**: (e.g. `--bg`, `--surface-raised`, `--line`, `--text`, `--accent`)

## 2. Anti-Default Discipline (Reject Generic AI Slop)
- ❌ No generic dark-mesh heroes with purple/blue glowing gradients.
- ❌ No centered cookie-cutter 3-card marketing grids.
- ❌ No default Inter font paired with washed-out Slate-900.
- ❌ No arbitrary one-off hex colors (`#3b82f6`). Use project CSS custom properties.

## 3. Physical Layout Invariants
- **Zero-Clipping Protection**: Set `box-sizing: border-box;` and ensure flex children holding tables or data cards enforce `min-width: 0; width: 100%; overflow-x: auto;`.
- **Tactile Feedback**: Interactive buttons, tabs, and cards must feature tactile micro-transitions (`transition: transform 120ms ease, background-color 150ms ease`, `active:scale(0.98)`).
- **Accessible Contrast**: Ensure badges and small text satisfy WCAG AAA/AA contrast against their immediate background.
```
